# Features

Feature specifications for this project.

## Index

| Feature | Status | Description |
|---------|--------|-------------|
| [real-time-command](real-time-command/README.md) | Stable | Simultaneous play, per-piece charge times, route planning, and anonymous attack target-locks. |
| [fatigue](fatigue/README.md) | Stable | Battle and movement fatigue that decays over time and shapes capture risk. |
| [morale](morale/README.md) | Stable | Command morale derived from king position, gating captures and prisoner capacity. |
| [fog-of-war](fog-of-war/README.md) | Stable | Team-shared patrol vision, opening deployment reveal, and ghost memory. |
| [prisoner-convoys](prisoner-convoys/README.md) | Stable | Captured pieces become neutral captives, escorted home in convoys and unloaded as fresh pawns. |
| [capture-outcomes](capture-outcomes/README.md) | Stable | Kill, Capture, and Recruit outcomes for an attack, with fatigue-adjusted risk on the voluntary ones. |
| [espionage](espionage/README.md) | Stable | Covert informer recruitment, shared vision, sabotage, and king interrogation. |
| [royal-beacon](royal-beacon/README.md) | Stable | The king's command chain: deploy, pass, recall, and restore a mobile focus that speeds nearby orders. |
| [pawn-specialisation](pawn-specialisation/README.md) | Implementing | Pawns earn a permanent profession — Engineer or Sergeant — through base-rank training. |
| [fortifications](fortifications/README.md) | Implementing | Engineers build wooden and stone walls on the edges between squares. |

## Open Questions

None at this time.
